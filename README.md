# PARENTYX

Página principal de PARENTYX - Ruta de crianza saludable.

## Estructura

```text
parentyx/
├── index.html
├── css/
│   └── styles.css
├── js/
│   └── script.js
└── images/
    └── README.txt
```

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Google Fonts - Poppins

## Imágenes

Las imágenes de la referencia fueron reemplazadas temporalmente por placeholders.

Para incorporar las imágenes definitivas:

1. Coloca los archivos dentro de `images/`.
2. En `index.html`, reemplaza los elementos `.image-placeholder` y `.registration-placeholder` por etiquetas `<img>`.
3. Ajusta `object-fit`, dimensiones y posicionamiento en `css/styles.css` si es necesario.

## Ejecución

No requiere instalación de dependencias.

Abre `index.html` directamente en el navegador o utiliza una extensión como Live Server en Visual Studio Code.

## Nota

La estructura está separada desde el inicio para facilitar que posteriormente se agreguen páginas, componentes y funcionalidades sin mantener todo el proyecto dentro de un único archivo HTML.
